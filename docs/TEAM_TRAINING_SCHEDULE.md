# LexMind AI Security Training Schedule

## Document Information

- **Version:** 1.0
- **Effective Date:** July 26, 2026
- **Training Period:** August 2026 - July 2027
- **Owner:** Security Team / HR
- **Target Audience:** All Employees

## Training Objectives

### Primary Objectives
- Establish security awareness across all departments
- Develop secure coding practices for development team
- Create security champions within the organization
- Establish continuous security learning culture
- Ensure compliance with security policies

### Secondary Objectives
- Reduce security incidents through awareness
- Improve incident response effectiveness
- Enhance security posture through knowledge sharing
- Build security-first mindset

## Training Audience

### 1. All Employees (General Security Awareness)
- **Target:** All employees
- **Frequency:** Annual mandatory + quarterly refreshers
- **Duration:** 2 hours initial, 30 minutes quarterly
- **Format:** Online modules + in-person workshops

### 2. Development Team (Secure Coding)
- **Target:** Developers, QA Engineers, DevOps
- **Frequency:** Quarterly training + monthly micro-learning
- **Duration:** 4 hours quarterly, 1 hour monthly
- **Format:** Hands-on workshops + code reviews

### 3. Management Team (Security Governance)
- **Target:** Managers, Directors, Executives
- **Frequency:** Bi-annual training
- **Duration:** 3 hours
- **Format:** Executive briefings + case studies

### 4. Security Champions (Advanced Security)
- **Target:** Selected security champions from each team
- **Frequency:** Monthly deep-dive sessions
- **Duration:** 2 hours monthly
- **Format:** Advanced workshops + certifications
